# Data

`seattle-weather.csv`: daily weather for Seattle, 2012-01-01 to 2015-12-31 (1,461 rows). Temperatures
in degrees C, precipitation in mm, wind in m/s. It comes from the
[vega-datasets](https://github.com/vega/vega-datasets) project, which derives it from NOAA daily
observations. That project notes that the `weather` label column is synthesized from the other
fields and that the file is intended for instructional use, so the analysis here does not use that
column.
